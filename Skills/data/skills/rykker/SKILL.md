# Sådan skriver vi rykkere

Find først de rigtige oplysninger. Gæt aldrig:
- Slå bibliotekets regler for sen aflevering op med værktøjet `search_docs`.
- Regn gebyret ud med værktøjet `calculate`: antal dage for sent gange prisen pr. dag.

Skriv så rykkeren:
- Venlig tone. Låneren har ikke gjort noget galt med vilje.
- Nævn bogens titel, hvor mange dage den er for sent, og det samlede gebyr.
- Fortæl, at bogen kan afleveres døgnet rundt i postkassen ved hoveddøren.
- Slut med "Venlig hilsen, Biblioteket Anatomi".
- Højst 6 linjer.
