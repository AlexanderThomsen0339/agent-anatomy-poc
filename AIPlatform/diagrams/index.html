Chat Question to Platform Answer

What actually happens between the moment someone types a question into the chat box and the moment the answer appears. The surprise is in the transport: there is no WebSocket, no Server-Sent Events, no polling — the browser does one ordinary form submission, and everything that looks "live" is HTML being appended to that same still-open HTTP response while the agent works underneath it.
